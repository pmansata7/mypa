# Lumi System

Documentation about how Lumi works and why.

## What Goes Here

- **Lumi_Jobs_to_Be_Done.md** — Why the system exists, what problems it solves
- **Lumi_System_Guide.md** — Comprehensive guide to using Lumi effectively

## Purpose

This folder contains the "why" and "how" of Lumi itself. When you forget how something works or want to understand the design philosophy, start here.

## Key Documents

- **Jobs to Be Done** — Understand what problems Lumi solves and when to use each feature
- **System Guide** — Complete walkthrough of workflows, commands, and best practices
- **Integration guides** — Connect external tools to enhance Lumi

## Maintenance

These docs are living documents:

- Expanded as new features are added
