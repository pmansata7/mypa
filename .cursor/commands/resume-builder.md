# resume-builder

Build resume and LinkedIn profile through guided interview.

## When user invokes /resume-builder

1. **Guided interview** — Ask about experience, achievements, skills, target role. 2–3 questions at a time.
2. **Extract** — Quantified achievements, key skills, career progression.
3. **Draft** — Resume (chronological or hybrid) and/or LinkedIn summary.
4. **Iterate** — User can refine sections, add/remove, adjust tone.
5. **Output** — Ready-to-use resume content; LinkedIn-ready copy.
