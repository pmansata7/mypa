# roadmap

Review roadmap, surface blockers, check alignment with priorities.

## When user invokes /roadmap

**Args:** Optional — `[pillar-name]` to filter

1. **Gather** — Scan `04-Projects/`, read `System/pillars.yaml`, `01-Quarter_Goals/Quarter_Goals.md`, recent meeting notes.
2. **Analyze projects** — Status, last modified (flag if >14 days), blockers (blocked, waiting, dependency), pillar alignment.
3. **Check feedback** — Recent meeting notes for customer/stakeholder input on roadmap.
4. **Output** — Health summary, alignment gaps, blocked items, recommendations.

**Full workflow:** `.claude/skills/_available/product/roadmap/SKILL.md`
