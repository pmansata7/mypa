# quarter-plan

Set 3–5 strategic goals for the quarter.

## When user invokes /quarter-plan

1. **Context** — Pillars from `System/pillars.yaml`; last quarter's goals and outcomes.
2. **Guided input** — Ask for 3–5 strategic goals; ensure they're measurable and pillar-aligned.
3. **Write** — Save to `01-Quarter_Goals/Quarter_Goals.md`.
4. **Connect** — Link to week priorities and projects.

**Full workflow:** `.claude/skills/quarter-plan/SKILL.md`
