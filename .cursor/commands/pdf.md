# pdf

Work with PDFs: extract text/tables, create, merge/split, form filling.

## When user invokes /pdf

1. **Read the skill** — `.claude/skills/anthropic-pdf/SKILL.md` for full workflows.
2. **Route by task:**
   - **Extract** — Text, tables, structure via PyMuPDF or pdfplumber
   - **Create** — New PDF from content
   - **Merge/split** — Combine or split pages
   - **Forms** — Fill form fields programmatically
3. **Scripts** — Check `.claude/skills/anthropic-pdf/scripts/` for utilities.
4. **Dependencies** — `PyMuPDF`, `pdfplumber`; see skill for specific packages.

**Full workflow:** `.claude/skills/anthropic-pdf/SKILL.md`
