# save-insight

Capture learnings from completed work for future reference.

## When user invokes /save-insight

1. **Context** — User describes what they learned or completed; or we surface from recent work.
2. **Structure** — Extract: What happened, why it matters, suggested fix/application, tags.
3. **Save** — To `System/Session_Learnings/YYYY-MM-DD.md` or appropriate resource folder.
4. **Link** — Connect to projects, people, or tasks if relevant.

**Format:**
```markdown
## [HH:MM] - [Short title]
**What happened:** [Specific situation]
**Why it matters:** [Impact]
**Suggested fix:** [Action]
**Status:** pending
```
