# quarter-review

Review quarter completion and capture learnings.

## When user invokes /quarter-review

1. **Load goals** — Read `01-Quarter_Goals/Quarter_Goals.md`.
2. **Assess each goal** — Done / partial / not done; evidence and outcomes.
3. **Patterns** — What worked, what blocked, surprises.
4. **Learnings** — Capture to `System/Session_Learnings/`.
5. **Next quarter** — Suggest focus for `/quarter-plan`.

**Full workflow:** `.claude/skills/quarter-review/SKILL.md`
