# week-review

Weekly synthesis of progress, accomplishments, and learnings.

## When user invokes /week-review

1. **Check demo mode** — If `demo_mode: true`, use `System/Demo/` paths.
2. **Review week priorities** — What was planned vs. what was done (concrete accomplishments, not fake percentages).
3. **Check completed tasks** — Tasks with `✅` timestamps from this week in `03-Tasks/Tasks.md`.
4. **Pattern detection** — What helped? What blocked? Recurring themes?
5. **Goal tracking** — Progress against quarter goals if applicable.
6. **Capture learnings** — Document insights to `System/Session_Learnings/`.
7. **Career evidence** — If `05-Areas/Career/` exists, prompt for achievements worth capturing.
8. **Next week preview** — Suggest focus areas for `/week-plan`.

**Full workflow:** `.claude/skills/week-review/SKILL.md`
