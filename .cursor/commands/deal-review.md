# deal-review

Review active deals and surface risks.

## When user invokes /deal-review

1. **Scan deals** — Search `04-Projects/` for deal files; check CRM/Deals structure if present.
2. **For each deal** — Stage, value, last activity, stakeholders, competitive position, risks.
3. **Surface risks** — Stale deals, missing champions, pricing concerns, timeline slip.
4. **Output** — Deal summary table, risk flags, suggested next actions.
