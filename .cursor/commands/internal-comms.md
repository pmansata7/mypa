# internal-comms

Write internal communications: status reports, leadership updates, 3P updates, newsletters, FAQs, incident reports.

1. **Read the skill** — `.claude/skills/anthropic-internal-comms/SKILL.md` for formats.
2. **Identify type** — Status report, leadership update, 3P update, newsletter, FAQ, incident report.
3. **Gather context** — User provides or is prompted for: audience, key points, tone.
4. **Apply formats** — Use examples in skill's `examples/` folder for structure.
5. **Output** — Draft ready for review; executive, crisp tone per user rules.
