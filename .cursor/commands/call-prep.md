# call-prep

Prepare for upcoming call with full context on person or account.

## When user invokes /call-prep

**Args:** `[person-name]` or `[company-name]`

1. **Identify** — Search People/ for person; Companies/ and related person pages for company.
2. **Person context** — Role, interests, relationship notes, communication preferences.
3. **Recent interactions** — Meetings from last 60 days; key topics, decisions, their concerns.
4. **Open action items** — Tasks involving this person/company; flag overdue.
5. **Account status** — Deal stage, health, recent wins/issues, stakeholder map.
6. **Compile brief** — Talking points, follow-ups, suggested questions.

**Full workflow:** `.claude/skills/_available/sales/call-prep/SKILL.md`
