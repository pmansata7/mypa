# career-coach

Career coaching with specialized modes for weekly reports, reflections, self-reviews, and promotion assessments.

## When user invokes /career-coach

1. **Identify mode** — User may specify or choose:
   - Weekly report — What did I accomplish?
   - Monthly reflection — Patterns, growth, challenges
   - Self-review — Performance calibration, evidence
   - Promotion assessment — Readiness, gaps, evidence

2. **Context** — Read `05-Areas/Career/` if exists; `System/user-profile.yaml` for communication style.
3. **Guided questions** — Ask 2–3 at a time, wait for answers.
4. **Evidence capture** — Surface completed work, feedback, skills demonstrated. Suggest saving to `05-Areas/Career/Evidence/`.
5. **Output** — Structured reflection or assessment with actionable next steps.

**Full workflow:** `.claude/skills/career-coach/SKILL.md`
