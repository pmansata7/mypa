# exec-summary

Craft or refine executive-level communication using Wes Kao's frameworks.

## When user invokes /exec-summary

**Args:** Optional context (purpose, audience, draft). If missing, ask for: purpose, audience, content (draft or bullets).

1. **Apply frameworks:**
   - **Sales, then logistics** — Why before how; 30–60 sec context before details
   - **Conciseness = density** — Trim filler; sharpen one outcome + 2–3 supports
   - **Signposting** — "First…", "Because…", "As a next step…", "The ask:"
   - **MOO** — Address most obvious objection in one line
   - **Accurate confidence** — Match language to evidence; no over/understating
   - **Managing up** — Recommendation + brief evidence, not "what should I do?"
   - **Strategy, not self-expression** — Keep the 10% that drives the decision

2. **Deliver:**
   - Draft provided → Revised version with notes on principles applied
   - Bullet points/raw info → Polished draft (email, Slack, bullets)
   - Feedback only → Focused feedback using frameworks

3. **Output** — Short paragraphs/bullets; subject line or first line states the ask. Tone: executive, crisp, direct.

**Full workflow:** `.claude/skills/exec-summary/SKILL.md` (Note: write-executive-email is a lighter variant; exec-summary has full framework set)
